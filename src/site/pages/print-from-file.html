Files I can print

  • STL or 3MF are preferred.
  • STEP works well, and is the best format if you might want changes.
  • OBJ is usually fine.

Tell me the size the part should be. STL files don't store units, so a part designed in inches can arrive 25 times too small. I check before printing, but your intended size removes the guesswork.

What's included

  • A check of the model for size, wall thickness and problem areas.
  • Orientation, supports and print settings chosen for how the part is used.
  • Normal support removal and cleanup.
  • A quick check before it goes out.

Broken meshes or changes to the design are CAD work and quoted separately.
